## Файлы
- `App/Theme.swift` — палитра, звёздный фон, haptics, стили карточек/кнопок
- `App/Settings.swift` — настройки анимаций, тема, отклик, статус виджета
- `App/Weather.swift` — погода: советы, почасовой прогноз, объяснения показателей
- `App/Shifts.swift` — календарь (исправлены id ячеек), меню даты, форма смены
- `App/Animated.swift` — анимированные огонёк и часы
- `App/Spending.swift` — траты: эмодзи, правка/удаление, фильтры, анализ, CSV
- `App/Pet*.swift` — питомец: векторная лиса, гардероб, имя, уведомления
- `App/Plus.swift` — Flamio+ (StoreKit 2)
- `Shared/Shared.swift` — модели, погода (Open-Meteo), безопасная загрузка данных

## App Store Connect для Flamio+
Группа подписок + автопродлеваемые продукты `flamio.plus.monthly`, `flamio.plus.yearly`.
Цены (ориентир): ~2,29 € / ~2,49 $ / ~99 ₴ в месяц; ~19,99 € в год — задаются по странам в App Store Connect.
Нужны: Paid Applications Agreement, локализации, скриншот paywall, ссылка на политику конфиденциальности (`PaywallView.privacyURL`).

## Личная сборка (GitHub → Codemagic → gboxfun)
- Содержимое этой папки кладётся в **корень** репозитория (рядом `codemagic.yaml`, `project.yml`, `App/`, `Shared/`, `Widget/`). Если в репозитории остался старый `LifeApp.zip`, Codemagic возьмёт его вместо папок — удалите.
- App Group убран из подписи (раньше из-за него был «No App Group in profile»). Виджет без общих данных показывает погоду выбранного в виджете города.
- Флаг `PERSONAL_TEST` в `project.yml` включает в Настройках переключатель «Flamio+ без оплаты». Для релиза удалить строку `SWIFT_ACTIVE_COMPILATION_CONDITIONS`.
- Покупки StoreKit в sideload-сборке не работают (нет продуктов App Store) — для проверки используйте тестовый переключатель.
- Вернуть App Group: добавить в `project.yml` обоим таргетам `entitlements` с `com.apple.security.application-groups` и подписать профилем, где группа есть.
